Port in small batches; see the plan in chat.

## Getting the jar
Push this folder to a GitHub repo. Open the Actions tab, pick the latest run,
and download `twilightforest-fabric-jar` under Artifacts. Use the jar without
"-sources" in its name.
Before the first build, set a real `loom_version` in gradle.properties.
